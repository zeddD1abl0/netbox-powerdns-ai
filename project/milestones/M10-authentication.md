# M10: Authentication

## Goal

Lock down the API before anything can change state from outside.

## Scope (provisional)

- The env-only break-glass token, and local users with MFA (Q-029)
- API tokens and service accounts for IaC and CI (Q-031)
- Sessions
- Rate limits (Q-040)
- From here on, the API requires authentication

## Design, non-goals and acceptance criteria

To be written in this milestone's plan-mode session, before implementation
starts. The milestone's branch is `m10-authentication` (ADR-0010).
