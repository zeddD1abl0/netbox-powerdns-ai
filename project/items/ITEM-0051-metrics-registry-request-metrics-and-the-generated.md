# ITEM-0051: Metrics registry, request metrics and the generated reference

## Goal

Declare nbpdns's Prometheus metrics once, in `internal/metrics`, with
`prometheus/client_golang`, and generate their reference page. Count each
request to NetBox and to the primaries through an observer in
`internal/httpclient` (ADR-0029).

## Acceptance criteria

- [ ] `internal/metrics` declares every metric in ADR-0029's table, with the build information and the Go runtime and process collectors, and a test runs promlint over them.
- [ ] `internal/httpclient` takes an optional observer, and the request metrics count requests by status, durations and retries, labelled by service and target.
- [ ] `docs/reference/metrics.md` is generated by `gendocs`, and `make generate-check` covers it.
