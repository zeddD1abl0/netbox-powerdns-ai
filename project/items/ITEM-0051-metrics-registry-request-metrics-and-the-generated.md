# ITEM-0051: Metrics registry, request metrics and the generated reference

## Goal

Declare nbpdns's Prometheus metrics once, in `internal/metrics`, with
`prometheus/client_golang`, and generate their reference page. Count each
request to NetBox and to the primaries through an observer in
`internal/httpclient` (ADR-0029).

## Acceptance criteria

- [x] `internal/metrics` declares every metric in ADR-0029's table, with the build information and the Go runtime and process collectors, and a test runs promlint over them.
- [x] `internal/httpclient` takes an optional observer, and the request metrics count requests by status, durations and retries, labelled by service and target.
- [x] `docs/reference/metrics.md` is generated by `gendocs`, and `make generate-check` covers it.

## Notes

- 2026-10-07: Created from M04's approved design.
- 2026-10-07: Done.
  - **`internal/metrics`** declares each metric once, as a `def`. The defs
    register the collectors in `New` and write `docs/reference/metrics.md`
    through `WriteReference`, which `gendocs` calls. Labels with a fixed set
    of values list them; the zone states and change kinds come from
    `internal/drift`'s constants. `New` also registers the Go runtime and
    process collectors, sets `nbpdns_build_info` from `internal/version`,
    and creates a series for each refresh outcome, so a rate is defined
    before the first failure. `Handler` serves the registry, with
    OpenMetrics when asked.
  - **`internal/httpclient`** takes an optional `Observer`, told of every
    attempt (its method, status code or 0, and duration, as the debug log
    measures it) and every retry. `netbox.Options` and `powerdns.Options`
    pass one through; the one-shot commands set none.
    `metrics.RequestObserver` implements it, labelled by service and
    target. ITEM-0053 wires it into `serve`.
  - **Tests:** promlint over every declared metric, with each one gathered;
    the observer's counts by code, retries and durations; the handler's
    output before any refresh; the reference's rows; and the HTTP client
    telling the observer of retried statuses and of requests with no
    answer.
  - **Dependency:** `github.com/prometheus/client_golang` v1.24.1
    (Apache-2.0), the Prometheus reference client, as ADR-0029 records. It
    was already in the module graph at v1.23.2, indirectly. It brings
    `prometheus/client_model`, `prometheus/common` and `prometheus/procfs`
    (Apache-2.0), `beorn7/perks` (MIT), `munnerz/goautoneg` (BSD-3-Clause),
    `kylelemons/godebug` (Apache-2.0, in tests only) and
    `google.golang.org/protobuf` (BSD-3-Clause), and moves `golang.org/x/crypto`
    and `golang.org/x/net` up to versions client_golang needs. All the
    licenses are on the allowed list. `nbpdns` itself doesn't link the
    package until `serve` does (ITEM-0053), which records the binary's
    size.
  - No CHANGELOG line yet: the metrics reach users with `serve`, whose
    line covers them.
