# ITEM-0072: The API docs and CHANGELOG

## Goal

The API's documentation: the reference generated from the spec,
"Service endpoints" updated, a how-to on reading drift and records
through the API, an explanation of the API's design, and the CHANGELOG.

## Acceptance criteria

- [x] `docs/reference/api.md` is generated from the spec by `gendocs`, and `generate-check` covers it.
- [ ] The how-to and the explanation exist, and "Service endpoints" lists `/api`, `/api/openapi.yaml` and `/api/docs`.
- [x] The CHANGELOG has the API under Unreleased.

## Notes

<!-- Append-only. Start each note with the date: "- YYYY-MM-DD: …" -->
- 2026-10-08: Created from M06's approved design.
- 2026-10-08: The pages are written; the how-to's commands are checked
  next, against the scale data set once it's loaded.
  - **`docs/reference/api.md`** is generated by `api.WriteReference`, from
    the embedded spec, through `gendocs`, so `generate-check` covers it.
    It walks the YAML nodes in the spec's order: the conventions, then
    each operation, with its parameters and responses, then each schema,
    with its fields.
    - Types are set in code, so Vale doesn't flag `boolean` or `uri`.
    - References are links, and nullable types and enums are spelled out.
    - A field that only refers to a schema takes that schema's
      description.
    - `TestReference` checks that every operation and schema has its
      section, and that no row lacks a description.
  - **The spec's wording** changed in four places for Vale: a
    possessive, and three Oxford-comma false positives.
  - **The how-to**, "Read drift and DNS records through the API", uses
    curl and jq to:
    - check the service;
    - list the groups;
    - find the drifted zones across groups;
    - show a zone's changes;
    - write its records as zone-file lines;
    - page to the end;
    - follow a flow ID.
  - **The explanation**, "How nbpdns's API is designed", covers:
    - spec first, with a diagram;
    - compatibility without path versions;
    - resources and their IDs, and Q-041's records;
    - last-known state, and refreshes between pages;
    - cursors, not offsets, and absolute links;
    - problems, flow IDs and `traceparent`;
    - no authentication until M10;
    - the locked-down reference.
  - **Indexes:** the how-to and explanation indexes link the new pages,
    the reference index links "API", and "Service endpoints" links the
    reference.
  - **The CHANGELOG** has a documentation line, and the vocabulary gains
    `jq`.
